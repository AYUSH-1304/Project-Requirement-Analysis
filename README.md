# Legacy OFS – Field Ticketing and Inspections Application

## Project Overview
Legacy OFS is a mobile-friendly web application designed for an oilfield services company to manage field tickets, service requests, work details, inspections, and maintenance-related records.

## Objective
The objective is to organize field service information in a centralized application, improve record management, and help authorized users track service activities efficiently.

## Problem Statement
Managing field tickets, service requests, inspection details, and maintenance records requires organized and accessible information. This project aims to provide a centralized system for recording, updating, and reviewing field service activities.

## Intended Users
- **Admin:** Manage users and device access.
- **Field Technician:** Record field tickets, work details, and inspection results.
- **Supervisor:** Review tickets and field activities.
- **Operations Staff:** Manage service requests and maintenance records.

*Note: Final user roles and permissions will be confirmed against the official project requirements.*

## Initial MVP Features
- User authentication and authorization
- Device management
- Create and view field tickets
- Update ticket details and status
- Manage service requests
- Record work details
- Create and view inspection records
- Manage maintenance records
- Database integration
- Responsive, mobile-friendly interface
- Testing and error handling

## Proposed Technology Stack
- **Frontend:** React.js
- **Backend:** Node.js and Express.js
- **Database:** PostgreSQL
- **API:** REST API
- **Version Control:** Git and GitHub
- **AI Integration:** Only if required by the assigned project brief

## Application Architecture
1. The user interacts with the React frontend.
2. The frontend sends requests to the backend REST API.
3. The Express backend validates requests and processes business logic.
4. PostgreSQL stores and retrieves application records.
5. The backend returns responses to the frontend.
